# byvo Icon Design

## Goal

为 `byvo` 提供一个可复用的 SVG icon，围绕“语音转写”表达产品语义，并适合作为 app icon 的核心图形基础。

## Approved Direction

- 主意象：语音气泡 + 麦克风融合
- 风格：极简几何
- 配色：白色背景，黑色线条
- 调整要求：
  - 线条比初稿更细
  - 内部麦克风与外层边框拉开明显留白
  - 避免过多细节，优先保证小尺寸识别

## Construction Notes

- 使用圆角方形底板，便于迁移到 Android/iOS launcher icon。
- 外层语音气泡作为主识别轮廓，内部麦克风与拾音弧线提供“语音输入”语义。
- 所有图形均为纯描边，无渐变、阴影或色彩层次，便于后续导出位图。
